# Week-1_Energy-Consumption-Prediction
# ⚡ Energy_Prediction_Project

This project focuses on predicting **energy consumption** using machine learning techniques.  
It includes modules for **data preprocessing**, **model training**, **prediction**, and **visualization** to analyze and forecast energy usage patterns effectively.

---

## 📂 File Descriptions

### `data_preprocessing.py`
Cleans and prepares raw energy data — handles missing values, performs scaling, and splits datasets.

### `model_training.py`
Trains ML models (like Linear Regression, Random Forest, etc.) and evaluates performance using metrics such as **RMSE** and **R² score**.

### `prediction.py`
Generates predictions for new input data using the trained model.

### `visualization.py`
Creates visual reports like **actual vs predicted plots**, **heatmaps**, and **trend analyses**.
